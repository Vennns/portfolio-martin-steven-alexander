# Portfolio Martin Steven Alexander

## Struktur
- `index.html` — halaman utama portfolio
- `style.css` — seluruh tampilan dan responsive design
- `script.js` — JavaScript/interaksi
- `assets/images/` — tempat foto dan gambar project

## Cara membuka di VS Code
1. Buka folder `portfolio-martin-steven-alexander` di VS Code.
2. Buka `index.html`.
3. Install extension **Live Server** jika ingin preview otomatis.
4. Klik kanan `index.html` → **Open with Live Server**.

## Yang perlu diganti
- Data email, WhatsApp, GitHub, dan LinkedIn di `index.html`.
- Foto profil/project dapat dimasukkan ke `assets/images/`.
